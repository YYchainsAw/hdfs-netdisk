# 账号和文件操作隔离集成测试

测试启动独立 MySQL 8.4 容器，以随机 HDFS 子目录存放临时文件，使用独立的本机进程锁和随机数据库密码，不连接生产数据库或访问生产用户文件。它会占用服务器内存、CPU 和 HDFS 空间；请确认有足够资源再运行。

测试覆盖注册及用户名大小写冲突、真实登录、两个用户数据隔离、上传与下载、用量统计、文件重命名的同名和版本冲突、并发修改、非空文件夹保护、文件删除与真实 HDFS 清理、密码修改后现有会话失效。

准备要求与相邻 `integration-qa/README.md` 相同。该脚本默认使用 `/www/wwwroot/netdisk` 的项目、独立 MySQL 容器以及服务器现有 HDFS；运行账户须有 Docker 和 `sudo -u hdfs` 权限。锁路径只在本次测试生成的临时源码副本内更改，不改变运行中的后端。

```bash
bash run-combined-it.sh
```

可设置 `NETDISK_QA_PROJECT_ROOT`、`NETDISK_QA_BACKEND_SRC`、`NETDISK_QA_SCHEMA` 指向隔离源码或项目目录。脚本强制覆盖数据源及 configtree 导入，数据库密码随机生成。`--hold` 模式额外在服务器的 127.0.0.1:18086 启动临时后端供浏览器联调，测试人员自行注册临时账号，结束后在运行终端按回车或 Ctrl+C 清理。18086 必须空闲；测试账号只存在于本次临时库。

正常退出会清理本次容器、匿名卷和随机 HDFS 测试目录。若进程被外部终止导致清理未执行，只能在核对标识后清理本次 `netdisk-multipart-it-*` 容器和 `/netdisk/{temp,users}/test-<本次随机标识>` 目录，不能清理其他数据。
